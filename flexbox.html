O que é o Flexbox?

O Flexbox (Flexible Box Layout) é um modelo de layout unidimensional: ele organiza os elementos em uma linha OU uma coluna por vez, distribuindo o espaço disponível entre eles e alinhando-os com muito pouco código.

Todo layout flex tem dois papéis:

  • Flex container - o elemento pai, que recebe display: flex;;
  • Flex items - os filhos diretos do container (netos não viram itens!).

E dois eixos que controlam todo o alinhamento:

  • Eixo principal (main axis) - a direção em que os itens são colocados (por padrão, horizontal);
  • Eixo transversal (cross axis) - o eixo perpendicular ao principal (por padrão, vertical).

Existe também o display: inline-flex;, que cria um container flex que se comporta como um elemento inline (ocupa só a largura do conteúdo, em vez da linha inteira).

Atenção: ao trocar para column, os eixos se invertem. O eixo principal passa a ser vertical e o transversal, horizontal. Por isso justify-content passa a alinhar na vertical e align-items na horizontal.

  • space-between - primeiro item na ponta inicial, último na final, espaço igual entre eles;
  • space-around - espaço igual ao redor de cada item (as pontas têm metade do espaço);
  • space-evenly - todos os espaços, inclusive as pontas, são iguais.

5. gap Básico

Cria espaço entre os itens, sem precisar de margin em cada um (e sem sobrar margem nas pontas).

gap: 0 (padrão)

.container {
  display: flex;
  gap: 20px;                  /* espaço entre linhas e colunas */
  /* gap: 10px 30px;    -> 10px entre as linhas, 30px entre as colunas */
  /* row-gap: 10px;     -> só entre as linhas */
  /* column-gap: 30px;  -> só entre as colunas */
}

6. flex-wrap Básico

Por padrão (nowrap), o Flexbox tenta manter todos os itens na mesma linha, encolhendo-os se for preciso. Com wrap, os itens que não cabem quebram para a linha de baixo.

Nos exemplos, cada item tem width: 150px.

/* Atalho: flex-flow = flex-direction + flex-wrap */
.container {
  flex-flow: row wrap;
}

Quando há várias linhas, align-content controla como as linhas se distribuem no eixo transversal (funciona como o justify-content, mas para as linhas). Ele só tem efeito com flex-wrap: wrap e container mais alto que o conteúdo.

7. flex-grow, flex-shrink e flex-basis Intermediário

Até aqui configuramos o container. Estas propriedades são aplicadas nos itens e controlam como cada um cresce, encolhe e qual o seu tamanho inicial:

  • flex-basis - tamanho inicial do item no eixo principal (antes de crescer ou encolher). O padrão é auto (usa o width ou o conteúdo);
  • flex-grow - quanto o item cresce para ocupar o espaço livre. Padrão: 0 (não cresce);
  • flex-shrink - quanto o item encolhe quando falta espaço. Padrão: 1 (encolhe).

8. order Intermediário

Muda a ordem visual dos itens sem mexer no HTML. O padrão é 0 para todos; itens com número menor aparecem primeiro (aceita valores negativos).

HTML 1
order: 3
HTML 2
order: 1
HTML 3
order: 2
.item-1 { order: 3; }
.item-2 { order: 1; }
.item-3 { order: 2; }   /* resultado visual: 2, 3, 1 */

Acessibilidade: o order altera só a aparência. Leitores de tela e a navegação por Tab continuam seguindo a ordem do HTML. Prefira reorganizar o próprio HTML sempre que possível.

9. align-self Intermediário

É o align-items aplicado a um único item: ele sobrescreve o alinhamento definido pelo container só para aquele elemento.

padrão
center
flex-end
stretch
.container { display: flex; align-items: flex-start; }
.item-2    { align-self: center; }
.item-3    { align-self: flex-end; }
.item-4    { align-self: stretch; }

10. margin: auto dentro do flex Intermediário

Dentro de um container flex, uma margin: auto absorve todo o espaço livre daquele lado. É a forma mais simples de empurrar um item para a ponta oposta: o truque clássico das barras de navegação.

Sobre

.logo {
  margin-right: auto;   /* empurra os links para a direita */

11. Flexbox na prática Aplicação

a) Barra de navegação

Logo à esquerda, links e botão à direita, tudo alinhado verticalmente:

iStore Catálogo Contato Sobre nós 
nav {
  display: flex;
  align-items: center;     /* centraliza na vertical */
  gap: 20px;
}
.nav-logo {
  margin-right: auto;      /* empurra o resto para a direita */
}

b) Catálogo de produtos (o exemplo do projeto iStore)

No projeto iStore, o catálogo usa flex-wrap com cartões de largura fixa, centralizados: 

.produtos {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
  justify-content: center;
}
.produto {
  width: 250px;
}

Veja a diferença entre largura fixa (cartões mantêm o tamanho e a última linha fica centralizada) e flexível com flex: 1 1 220px (os cartões crescem para ocupar a linha):

Repare que, no modo flexível, o último cartão sozinho na linha se estica até o final. Isso acontece porque o Flexbox só enxerga uma dimensão por vez (cada linha é independente). Para manter as colunas alinhadas entre as linhas, o ideal é usar o CSS Grid.

c) Rodapé sempre no fim da página

O próprio Hub de Aulas usa Flexbox para isso! Veja o trecho do index.css: 

body {
  min-height: 100vh;
  display: flex;
  flex-direction: column;   /* empilha header, main e footer */
  align-items: center;
}
footer {
  margin-top: auto;         /* empurra o rodapé para baixo */
}

d) Centralização total

.tela {

Atividade Prática

Crie uma página atividade-flexbox.html que contenha:

  • Uma barra de navegação com logo à esquerda e três links à direita (use margin-right: auto ou justify-content: space-between);
  • Uma galeria de 6 cartões com flex-wrap: wrap, gap e flex: 1 1 200px;
  • Uma área com barra lateral fixa (flex: 0 0 200px) e conteúdo fluido (flex: 1);
  • Um rodapé que fique sempre no fim da tela, mesmo com pouco conteúdo;
  • Desafio: no celular (@media (max-width: 600px)), faça a barra lateral ficar acima do conteúdo usando flex-direction: column.

Para treinar jogando: Flexbox Froggy. Referência completa: MDN - Flexbox.
