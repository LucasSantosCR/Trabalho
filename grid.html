O que é o CSS Grid?

O CSS Grid Layout é um modelo de layout bidimensional: ele divide o espaço em linhas E colunas ao mesmo tempo, formando uma grade onde os elementos são posicionados. Se o Flexbox organiza itens em uma só direção por vez, o Grid controla as duas direções juntas.

Como no Flexbox, existem dois papéis:

  • Grid container - o elemento pai, que recebe display: grid;;
  • Grid items - os filhos diretos do container, que ocupam as células da grade.

Vocabulário do Grid

  • Linha da grade (grid line) - as linhas divisórias, numeradas a partir de 1. Uma grade de 3 colunas tem 4 linhas verticais;
  • Trilha (track) - o espaço entre duas linhas: uma coluna ou uma linha da grade;
  • Célula (cell) - o cruzamento de uma linha com uma coluna;
  • Área (area) - um conjunto retangular de células;
  • Gap - o espaço entre as trilhas.

1. Criando a grade: colunas Básico

Duas propriedades já criam uma grade: display: grid; ativa o Grid e grid-template-columns define quantas colunas existem e qual a largura de cada uma. As linhas são criadas automaticamente conforme os itens vão sendo colocados.

2. Unidades das trilhas: px, %, fr e repeat() Básico

Cada valor de grid-template-columns é a largura de uma coluna. Podemos misturar unidades:

  • px, %, rem - tamanhos fixos ou proporcionais ao container;
  • fr (fraction) - uma fração do espaço livre. 1fr 2fr divide o espaço em 3 partes: a segunda coluna fica com o dobro da primeira;
  • auto - o tamanho necessário para o conteúdo (ou o que sobrar);
  • repeat(vezes, tamanho) - evita repetição: repeat(4, 1fr) = 1fr 1fr 1fr 1fr;
  • minmax(mín, máx) - um tamanho mínimo e um máximo (veremos adiante).

3. Linhas: grid-template-rows e grid-auto-rows Básico

As linhas funcionam exatamente como as colunas:

  • grid-template-rows - define a altura das linhas explícitas (as que você declarou);
  • grid-auto-rows - define a altura das linhas criadas automaticamente quando os itens passam do que foi declarado.

5. Posicionando itens: grid-column e grid-row Intermediário

Por padrão, cada item ocupa uma célula, na ordem do HTML. Para fazer um item ocupar várias células, indicamos entre quais linhas da grade ele fica:

  • grid-column: 1 / 3 - começa na linha 1 e termina na linha 3 (ocupa 2 colunas);
  • grid-row: 1 / 3 - idem para as linhas (ocupa 2 linhas);
  • grid-column: span 2 - "ocupe 2 trilhas" a partir de onde estiver;
  • grid-column: 1 / -1 - da primeira até a última linha (largura total).
Agrid-column: 1 / 3
Bgrid-column: 3 / 5
grid-row: 1 / 3
Cgrid-row: span 2
D
E
F
G
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 60px;
  gap: 8px;
}
.a { grid-column: 1 / 3; }                    /* colunas 1 e 2 */
.b { grid-column: 3 / 5; grid-row: 1 / 3; }   /* colunas 3 e 4, linhas 1 e 2 */
.c { grid-row: span 2; }                      /* ocupa 2 linhas */
/* D, E, F e G são posicionados automaticamente nos espaços livres */

Os itens sem posição definida (D, E, F, G) preenchem os espaços livres automaticamente. Esse comportamento se chama auto-placement.

6. grid-template-areas: desenhando o layout Intermediário

Em vez de números de linhas, podemos nomear áreas e "desenhar" o layout com texto. Cada string é uma linha da grade e cada palavra é uma coluna; repetir o nome faz a área ocupar várias células. Use um ponto (.) para uma célula vazia.

topo
menu
principal
rodapé
.layout {
  display: grid;
  grid-template-columns: 130px 1fr;
  grid-template-rows: 50px 110px 45px;
  grid-template-areas:
    "topo   topo"
    "menu   principal"
    "rodape rodape";
  gap: 8px;
}

.topo      { grid-area: topo; }
.menu      { grid-area: menu; }
.principal { grid-area: principal; }
.rodape    { grid-area: rodape; }

A grande vantagem: para um layout responsivo, basta redesenhar as áreas dentro de um @media, sem mexer no HTML: 

@media (max-width: 600px) {
  .layout {
    grid-template-columns: 1fr;
    grid-template-rows: auto;
    grid-template-areas:
      "topo"
      "menu"
      "principal"
      "rodape";
  }
}

7. Alinhamento no Grid Intermediário

O Grid usa os mesmos nomes do Flexbox, mas com uma diferença importante: existem alinhamentos dos itens dentro das suas células e alinhamentos da grade inteira dentro do container.

a) Itens dentro da célula: justify-items, align-items e place-items

  • justify-items - alinha na horizontal, dentro da célula;
  • align-items - alinha na vertical, dentro da célula;
  • place-items - atalho: place-items: align justify (um valor só vale para os dois).

8. Grid responsivo: repeat(auto-fit, minmax()) Intermediário

Esta é a combinação mais poderosa do Grid: colunas que se ajustam sozinhas ao tamanho da tela, sem nenhum @media. 

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap: 10px;
}

Lendo de dentro para fora:

  • minmax(120px, 1fr) - cada coluna tem no mínimo 120px e no máximo uma fração do espaço livre;
  • auto-fit - "crie quantas colunas couberem" e, se sobrar espaço, estique as colunas ocupadas;
  • com auto-fill, as colunas vazias também são mantidas (os itens não esticam).

Com poucos itens a diferença aparece. Mesmo código, só trocando auto-fit por auto-fill:

10. Flexbox ou Grid? Aplicação

Nenhum dos dois é "melhor": eles resolvem problemas diferentes e funcionam muito bem juntos.

FlexboxGrid
DimensõesUma (linha OU coluna)Duas (linhas E colunas)
Quem manda?O conteúdo define o layoutO layout define onde o conteúdo vai
Ideal paraComponentes: menus, botões, barras, alinhamentosEstrutura da página, galerias, painéis
Quebra de linhaCom flex-wrap; cada linha é independenteAutomática; colunas sempre alinhadas
ExemploNavbar com logo à esquerda e links à direitaPágina com topo, menu, conteúdo e rodapé

Regra prática: está alinhando itens em uma linha ou coluna? Use Flexbox. Precisa controlar linhas e colunas ao mesmo tempo? Use Grid. Na prática, o Grid monta o esqueleto da página e o Flexbox organiza o interior de cada pedaço. 

/* O Grid divide a página... */
.pagina {
  display: grid;
  grid-template-columns: 200px 1fr;
}

/* ...e o Flexbox organiza o conteúdo de cada parte */
.topo {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Atividade Prática

Crie uma página atividade-grid.html que contenha:

  • Uma galeria de 8 cartões com repeat(auto-fit, minmax(200px, 1fr)) e gap;
  • Nessa galeria, um cartão em destaque ocupando 2 colunas (grid-column: span 2);
  • Um layout de página com grid-template-areas: topo, menu lateral, conteúdo e rodapé;
  • Um quadrado centralizado na tela usando apenas display: grid e place-items: center;
  • Desafio: no celular (@media (max-width: 600px)), redesenhe as áreas do layout para que tudo fique em uma única coluna.
